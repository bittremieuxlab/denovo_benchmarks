# Add SMSNet to the benchmark
The container has two variants of SMSNet, in `/algo/phospho` and `/algo/standard`, that predict phosphorylation of S, T, and Y or only oxidation of M. 
Both are [SMSNet](https://github.com/cmb-chula/SMSNet) at commit `facfaf4` with the benchmark's changes in `patches/phospho.patch` and `patches/standard.patch`.
